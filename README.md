# 📊 Referral Dashboard

An interactive and responsive dashboard application for managing and viewing referral-related information.

## ✨ Features

- Interactive dashboard interface
- Referral information management
- Clean and responsive UI
- Organized data presentation
- User-friendly navigation

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML
- CSS

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abhivarshinimylarapu-debug/Referral-Dashboard.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal.
